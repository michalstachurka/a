# KrakowRemonty.com — pakiet dla Claude Code

## Uruchomienie

1. Otwórz ten folder w terminalu.
2. Uruchom Claude Code w katalogu projektu.
3. Wklej zawartość `START_CLAUDE_CODE.txt`.
4. Pozwól Claude Code utworzyć stronę w tym samym folderze.

## Kolejność ważności

- `CLAUDE.md` — nadrzędne zasady estetyczne.
- `01-research.md` — fakty i ograniczenia.
- `02-creative-directions.md` — wybrany kierunek.
- `03-brand-system.md` — system wizualny.
- `04-site-architecture.md` — struktura.
- `05-content.md` — gotowe teksty.
- `06-image-prompts.md` — grafiki do ChatGPT.
- `07-video-prompts.md` — hero do Gemini.
- `08-claude-build-spec.md` — wymagania implementacyjne.
- `09-project-summary.md` — skrót projektu.

## Ważne

To nieoficjalna koncepcja demonstracyjna. Formularz nie może wysyłać danych, a strona ma zawierać `noindex`.
